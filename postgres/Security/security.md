## Conversion notes

### Schemas
`CREATE SCHEMA [X] AUTHORIZATION [dbo]` → `CREATE SCHEMA IF NOT EXISTS x` (lowercase).  
`sp_addextendedproperty` → `COMMENT ON SCHEMA`.  
`powerbi` and `reports` schemas are created for completeness; no objects exist in them yet.

### Roles
`CREATE ROLE [Name] AUTHORIZATION [dbo]` → `DO $$ BEGIN CREATE ROLE "Name"; EXCEPTION WHEN duplicate_object THEN NULL; END $$;`  
Role names with spaces are double-quoted. The `AUTHORIZATION [dbo]` clause is dropped — PostgreSQL roles have no owner.  
Role names are intentionally preserved with original casing and spaces because `application.determine_customer_access()` constructs them at runtime as `_territory || ' Sales'`.

### WebApi user
MSSQL separates server-level logins (`CREATE LOGIN`) from database-level users (`CREATE USER … FROM LOGIN`). PostgreSQL uses a single `CREATE ROLE … WITH LOGIN`. The `DEFAULT_SCHEMA=WebApi` setting has no direct PostgreSQL equivalent; the application must qualify schema names or set `search_path` per connection.

`GRANT EXECUTE ON SCHEMA::WebApi` maps to both `GRANT USAGE ON SCHEMA` (required to resolve schema-qualified names) and `GRANT EXECUTE ON ALL FUNCTIONS IN SCHEMA`.

`GRANT SELECT ON SCHEMA::WebApi` maps to `GRANT SELECT ON ALL TABLES IN SCHEMA webapi` (covers views too).

### Row-level security policy
MSSQL `CREATE SECURITY POLICY` with FILTER + BLOCK predicates maps to PostgreSQL `CREATE POLICY` statements. These are generated by calling `application.configuration_apply_row_level_security()` (converted from `Application/Stored Procedures/Configuration_ApplyRowLevelSecurity.sql`). The call is in `rls_policy.sql`.

## Deployment order

```
schemas.sql       -- create all schemas first
roles.sql         -- create territory roles (needed before RLS is activated)
<all DDL files>   -- tables, functions, views from other schemas
permissions.sql   -- webapi role + grants (requires webapi schema and application.logs to exist)
rls_policy.sql    -- enable RLS on sales.customers (requires all of the above)
```
